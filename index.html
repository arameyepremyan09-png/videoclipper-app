Videoclipper Privat

Videoclipper Privat is a personal desktop tool for editing short vertical videos and publishing them to the operator's own TikTok and YouTube accounts. It runs on the operator's own computer. There is no public service and no user registration.

What it does

  • Connects to the operator's own TikTok account through TikTok Login Kit (scope user.info.basic).
  • Uploads finished video files to TikTok through the Content Posting API (scopes video.upload, video.publish).
  • Uploads the same videos to the operator's own YouTube channel through the YouTube Data API.

Every upload is started deliberately by the account owner. Nothing is posted automatically without that action.
