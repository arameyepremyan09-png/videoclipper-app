Privacy Policy

Last updated: October 20, 2026

1. Who is responsible

Arame Yepremyan, contact: arame.yepremyan@web.de. The App is a personal tool without a server or a public user base.

2. What data the App handles

  • TikTok: the account's Open ID, basic profile information (display name) and the access and refresh tokens issued after you authorise the App. The App also reads the account's posting options (for example the allowed privacy levels).
  • YouTube / Google: an OAuth access and refresh token with the scope youtube.upload. The App does not read your channel data, subscribers, or private videos.
  • Video files that you choose to upload, together with the title and description you enter.

3. Where data is stored

Tokens are stored only in a protected file on the user's own computer. They are not sent to any server operated by the Operator, and nothing is stored in the cloud. The App has no analytics, no advertising and no tracking.

4. Sharing

Data is sent only to TikTok and YouTube/Google, and only to carry out an upload that the user has started. Data is never sold or shared with anyone else.

5. YouTube API Services

The App uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy. You can revoke the App's access at security.google.com/settings/security/permissions.

6. Deleting data and revoking access

  • TikTok: Settings and privacy → Security & permissions → Apps and services → remove the App.
  • Google: revoke access at the link above.
  • Locally: delete the token file on your computer; this removes all stored credentials.

7. Contact

Questions or deletion requests: arame.yepremyan@web.de.
